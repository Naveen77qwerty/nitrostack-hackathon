READ detect_source_changes

Compare v1 vs v2 authoritative sources to find changed facts.

READ find_affected_knowledge

Traverse the dependency graph to find all documents and claims affected by a fact change.

READ validate_claim

Check if a specific claim is VALID, CONFLICT, or AMBIGUOUS against its authoritative source.

READ detect_knowledge_conflicts

Find all knowledge contradictions across enterprise documents for a given fact.

READ trace_knowledge_provenance

Trace the origin of a claim through source version history.

READ assess_knowledge_risk

Deterministic risk scoring based on customer-facing impact, financial, compliance, and operational factors.

READ investigate_knowledge_change

Run a complete read-only investigation across all changed sources. One-call comprehensive report.

WRITE propose_knowledge_update

Create a remediation proposal for a conflicting claim. Status: AWAITING_APPROVAL.

WRITE approve_knowledge_update

Approve and apply a pending update. The only tool that modifies the knowledge base.

WRITE reject_knowledge_update

Reject a pending proposal. Records the decision in the audit log.

READ get_audit_log

Retrieve the history of all remediation decisions.
